## 需要继续解决的问题

1. **补土豆样本。** 当前验证土豆仅 4 张、8 个目标，99.5% 的单类 mAP 不能代表覆盖充分。
2. **检查瓷片与砖块的混淆。** 默认验证可视化中可见重复框、误报和少量漏检；混淆矩阵中部分砖块被识别为瓷片。应增加两类相似外观的对照样本，并结合实际运行选择置信度阈值。预测示例的 0.5 只是预览设置，未作为最终推荐阈值。
3. **增加独立采集验证。** 目前照片集中在相近时间和木板背景；已有随机图片划分可能让近似场景同时出现在训练与验证中。后续按拍摄批次或摆放场景分组划分，并使用 USB 摄像头在接近现场的 A4 视野下验证。
4. **再决定正式训练轮数。** 先补样本和进行现场条件预测，不必仅因轮数少就立刻扩大模型或盲目训练 100 轮。

本次没有接入摄像头、跟踪、测速、标定、通信或垃圾大类映射，也没有测量实时摄像头 FPS。
